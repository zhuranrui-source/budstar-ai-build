# 家长与学生合并为统一家庭视图

consumer 端不再区分家长视图与学生视图，家长与学生以亲子共学场景共用同一家庭视图，登录方式保持一致（微信登录 + 手机号绑定，见 ADR-0006）。为守住原有教育隐私边界，家庭视图统一不展示五维数字等级与排名，仅呈现描述性反馈、成长徽章与已发布成长报告；作品提交必须显式归属到学生档案，操作账号可被记录为协助者，教师端批改与成长评价链路始终认学生档案；多孩家庭保留学生档案切换，这是档案选择而非角色分流。监护人授权与星芽星球可见范围仍由数据层规则控制，不随视图合并而变化。角色区分回归账号与数据模型（用户账号可关联家长或学生身份），前端不再按角色裁剪界面。
