# 员工移动化走 admin-web 响应式 H5 单应用

教师、平台管理员与合作方的移动办公由 admin-web 一个响应式 H5（PWA）承载，不新增微信小程序：管理后台类小程序存在微信审核与类目资质约束，且三个身份共用登录、二次验证、待办流组件、契约与部署流水线，拆分只会复制基建。应用内按身份空间做路由级隔离（/teacher、/platform、/partner），数据边界仍由服务端按角色与授权校区过滤，前端合并不产生越权面。移动端信息架构以待办流为核心（待跟进线索、待审核内容、AI 草稿处理、告警），桌面端提供完整导航。合作方门户预留拆分边界：/partner 路由独立成组、不依赖员工端组件，当合作方数量增长、需要品牌定制或合作模式变重时，可整段迁出为独立应用并继续共用 contracts 与统一 API。
