# 监护人展示授权改为一次性开通的总开关

监护人对作品展示的授权从逐作品审批改为一次性开通的展示总开关：家长在家庭绑定或入班流程中一次勾选"同意作品在星芽星球展示"后，学生作品默认进入星球公开流，营造开放的社区氛围；授权可随时撤销、以版本化记录留存，撤销后新内容停止进入公开流，已发布内容的处置遵循既定审核规则。该方案保留《个人信息保护法》与《未成年人网络保护条例》要求的监护人明确同意，仅将授权时机前移、频率降为一次，避免逐作品审批破坏社区氛围。星球公开流指登录用户可见的站内公开，不等于对互联网公开：搜索引擎收录（维持 noindex）、匿名互动和公开搜索仍不开放；站内内容照常按风险等级审核。员工身份与校区数据边界不受本授权影响。
