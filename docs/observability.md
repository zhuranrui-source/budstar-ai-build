# 观测与告警基线（W-19）

## 结构化日志字段

每条业务请求日志至少包含：

- `requestId`
- `route` / `method`
- `statusCode`
- `durationMs`
- `actorKind`（若已认证）
- `campusId`（若有校区上下文）

禁止记录：完整手机号、验证码、模型密钥、未成年人自由文本全文。

## 指标

| 指标                   | 目标    |
| ---------------------- | ------- |
| API P95（不含外部 AI） | < 500ms |
| 预约创建成功率         | 可看板  |
| AI 主模型失败/降级次数 | 可告警  |
| 对象存储预签名失败次数 | 可告警  |
| 5xx 比率               | 可告警  |

## requestId

API 中间件为每个请求生成或透传 `x-request-id`，并在错误响应中回显（不泄露内部堆栈）。
