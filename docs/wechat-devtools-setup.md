# 微信小程序上线准备指引（企业主体 · ISSUE-08）

> 分两条线：**A 线在网页后台**（mp.weixin.qq.com，管理员操作），**B 线在开发者工具**（Mac 本机）。
> A 线拿到的三样东西（AppID、AppSecret、域名配置）是 B 线和后端的前置条件。

---

## A 线：公众平台后台（先用这个）

### A1. 拿 AppID + AppSecret

1. 用企业主体的管理员微信扫码登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)
2. 「设置 → 基本设置」记录 **AppID**（企业主体 wx 开头）
3. 「开发管理 → 开发设置 → AppSecret」点「生成」→ **一次性展示，复制保存**（关掉就查不到了，丢了只能重置）
4. 把 **AppID 和 AppSecret 发给我**：我分别配到 `apps/miniapp/project.config.json`（替换 touristappid）和后端 `.env`（`WECHAT_MINIAPP_APP_ID` / `WECHAT_MINIAPP_APP_SECRET`，服务端 code2session 用）

### A2. 添加项目成员（当天就能扫码开发/体验）

「成员管理 → 项目成员」：

- 添加你的个人微信为**开发者**（最多 N 个，免费）
- 后续试点教师/合作方体验时加**体验成员**

### A3. 微信认证状态确认

「设置 → 基本设置 → 微信认证」：

- 企业主体注册时若已过认证（显示已认证 V）→ `getPhoneNumber`（手机号一键授权）可用
- 若未认证 → 需完成认证（300 元/年）才能用一键授权；**未认证期间小程序可先用短信验证码通道**（我们已实现兜底，不受阻塞）

### A4. 服务器域名（可以等生产域名就绪后再配，先记下来）

「开发管理 → 开发设置 → 服务器域名 → 修改」：

- **request 合法域名**：`https://<你的生产API域名>`（OPS-05 域名定了我来配）
- **业务域名**（web-view 打开实验室 HTML 用）：`https://<API域名>`
- 每月可修改 50 次；开发阶段在开发者工具勾选「不校验合法域名」即可绕过（我们已默认关闭校验）

### A5. 用户隐私保护指引（提审必做）

「设置 → 服务内容声明 → 用户隐私保护指引」：

- 采集项勾选：**手机号**（登录绑定）、**头像/昵称**（可选）
- 对应业务：家长手机号绑定家庭视图
- 提交后微信审核 1-2 天，**建议今天就提交**

## B 线：微信开发者工具（A1 拿到 AppID 后）

### B1. 登录与导入项目

1. 打开 `/Applications/微信开发者工具.app`，用**被加为开发者的微信**扫码
2. 首次启动若提示选择小程序/公众号 → 选小程序
3. 「+ 导入项目」：
   - 目录：`/Users/80419400/Documents/zhuzhu-test/apps/miniapp`
   - AppID：填企业 AppID（我配好后这步会自动带出）
   - 后端不校验合法域名（配置里已设 `urlCheck: false`）

### B2. 本地联调（跑通全链路）

两个终端：

```bash
# 终端1：起后端（含微信登录 mock + 真实 AI 讲解）
cd ~/Documents/zhuzhu-test/apps/api && pnpm dev

# 终端2：小程序 watch 构建（改代码自动重编，工具里自动刷新）
cd ~/Documents/zhuzhu-test && pnpm --filter @budstar/miniapp dev:weapp
```

然后在工具模拟器里按 ISSUE-05 验收路径走查：
登录 → （一键授权或短信兜底）→ 选学生 → 课节 → 写作品提交 → 星球/报告 → 学科实验室目录

**注意**：本地后端用 mock 微信解析器（任意 code 换确定性 openid），模拟器里的 wx.login 全流程可跑；真实 code2session 在配好 A1 的 Secret 后于预览/体验版生效。

### B3. 开启服务端口（为后续 CLI 自动化）

工具右上角「设置 → 安全设置 → 服务端口」→ 开启。
（后续上传代码可以走命令行 `miniprogram-ci`，接入我们的发布流程）

### B4. 上传体验版

1. 工具右上角「上传」→ 版本号 `0.1.0` → 备注「家庭视图首版」
2. 回到 mp 后台「管理 → 版本管理 → 开发版本」→ 选为**体验版**
3. 手机上用「小程序体验版」二维码扫码真机走查（重点：一键授权弹窗、真机网络到生产 API）

### B5. 提审前检查（对着我们的 ISSUE-08 清单）

- [ ] A5 隐私指引审核通过
- [ ] A4 域名已配且生产 API 部署就绪
- [ ] 体验版真机全路径走查通过
- [ ] 提交审核 → 类目：教育 > 在线教育（非学科培训资质已备）
- [ ] 审核通过 → 发布

## 卡点速查

| 现象                                | 处理                                                             |
| ----------------------------------- | ---------------------------------------------------------------- |
| 模拟器 wx.login 报 invalid code     | 正常（本地走 mock）；真机预览才走真实 code2session               |
| getPhoneNumber 无弹窗/报无权限      | A3 认证未完成 → 先用短信兜底通道                                 |
| request fail url not in domain list | 开发阶段确认工具里勾了「不校验合法域名」；体验版/正式版必须配 A4 |
| AppSecret 重置                      | 旧 Secret 立即失效，重置后把新的发我更新 .env                    |
