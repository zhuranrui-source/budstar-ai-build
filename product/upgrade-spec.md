# 家庭视图与角色简化实现规格（Issue 拆解）

> 状态：待排期（全量开发）  
> 决策依据：ADR-0006 ～ ADR-0010、`product/web-prd.md` 首发验收未完成项  
> 目标形态：微信小程序 ×1（家庭视图）+ admin-web 响应式 H5 ×1（教师 / 平台管理员 / 合作方三身份空间）  
> 已对齐决策：小程序技术栈 **Taro + React**（进 monorepo，共用 contracts）；微信主体认证与非学科培训资质**已齐备**；存量学生专属账号**直接停用**（转纯档案，不留兼容层）；生产域名**未确定**（环境变量占位，上线前随 OPS-05 配置）

## ISSUE-01 监护人展示授权改为一次性总开关（ADR-0008）

**目标**：作品展示授权从逐作品 WORK_DISPLAY 审批改为绑定/入班时一次开通、可撤销的总开关，已开通作品默认进入星芽星球站内公开流。

**范围**：

- GuardianConsent 增加 `DISPLAY_SWITCH` 授权类型（保留历史 WORK_DISPLAY 记录兼容读取）
- 家庭绑定确认与班级码入班流程中嵌入一次性授权步骤（默认勾选、明示可撤销、版本化记录）
- consumer 端提供撤销入口；撤销后新作品停止进入公开流
- 星芽星球 feed 可见性判断改为读取开关状态；维持 noindex 与风险分级审核不变
- 不做：对外互联网公开、搜索引擎收录、匿名互动

**验收标准**：

- [ ] 绑定/入班时未授权的用户，作品不进入公开流；授权后自动进入
- [ ] 撤销立即生效于新内容；撤销动作有版本化记录与审计日志
- [ ] 存量 WORK_DISPLAY 授权作品行为不回退
- [ ] 公开流接口对未登录用户返回 401；robots/noindex 策略不变
- [ ] 中高风险内容仍走人工审核，不被开关旁路
- [ ] 相关服务层与 API 契约测试更新并通过 `pnpm verify`

## ISSUE-02 员工角色简化为教师 + 平台管理员，新增合作方身份（ADR-0009）

**目标**：校区内员工仅保留教师；班级管理、报告发布归教师，线索跟进归平台管理员；新增 B 端合作方身份（仅内容可见）。

**范围**：

- `CampusAuthorizationPolicy` 与员工模型：移除教务/校区管理员组合角色语义，教师为校区内唯一员工角色
- 线索相关接口权限收紧到平台管理员（原校区侧线索入口下线）
- 新增合作方身份：独立认证（密码 + 二次验证）、课程包与活动发布的只读授权
- 合作方数据边界：学生、作品、成长、线索、校区运营数据全部不可见（服务端 Guard 强制）
- admin-web 账号签发流程按新角色调整

**验收标准**：

- [ ] 教师可完成班级 CRUD、提交处理、点评、五维复核、报告发布、家长沟通全链路
- [ ] 教师访问线索接口返回 403；平台管理员可完整流转线索
- [ ] 合作方可登录并浏览已发布课程包与活动，访问任何学生/线索实体返回 403
- [ ] 合作方身份不继承校区成员与平台管理员任何能力
- [ ] 越权路径有审计记录；既有按旧角色的测试全部改写并通过

## ISSUE-03 consumer-web 家庭视图合并（ADR-0007）

**目标**：家长/学生分离视图合并为统一家庭视图，家长学生共用登录与界面，支持亲子共学场景。

**范围**：

- 合并 `family`（家长门户）与 `learning/growth`（学生页）为单一家庭视图路由
- 存量学生专属账号直接停用：登录入口移除、账号转纯档案、不留只读兼容层；存量学生数据一次性核对归属学生档案
- 顺手修复 `growth/learning` 页面存量 TS 字面量类型错误，避免脏基线混入合并提交
- 多孩学生档案切换保留（档案选择，非角色分流）
- 五维数字等级与排名从家庭视图全面下线；仅展示描述性反馈、成长徽章、已发布成长报告
- 作品提交流程显式选择归属学生档案，操作账号记录为协助者
- 微信登录前置改造：consumer-web 认证链路预留微信身份 + 手机号绑定的账号合并点（与 ISSUE-04 对齐契约）

**验收标准**：

- [ ] 家长登录后进入统一家庭视图，无家长/学生双入口
- [ ] 存量学生账号登录被拒绝且返回明确提示；学生档案数据完整、归属正确
- [ ] 全部页面（含报告）不出现五维数字与排名字样
- [ ] 切换学生档案后，课节、作品、反馈、星球内容随之切换
- [ ] 作品提交归属所选学生档案，协助者账号入库可查
- [ ] 旧家长/学生路由 301 到家庭视图；e2e 覆盖合并后主路径

## ISSUE-04 微信小程序登录基建（ADR-0006）

**目标**：小程序端以微信登录为身份底座，进入家庭内容时绑定手机号（一键授权优先、短信兜底）。

**范围**：

- 新建小程序客户端工程：**Taro + React**（已定），进 monorepo `apps/miniapp`，共用 `@budstar/contracts`
- API：`code2Session` 换取 openid/unionid，微信身份创建/关联用户账号
- 手机号绑定：`getPhoneNumber` 解密 + 短信 OTP 两条通道，绑定仅匹配家庭绑定关系
- 绑定手机号不赋予任何员工能力；员工身份仍仅 admin-web 密码 + 二次验证
- 订阅消息模板预留（报告发布、预约跟进通知）

**验收标准**：

- [ ] 微信登录后可浏览官网内容与提交预约线索（不强制绑手机号）
- [ ] 进入家庭视图触发手机号绑定；一键授权与短信兜底均可用
- [ ] 绑定动作仅产生家庭绑定匹配，无员工能力注入（接口层断言）
- [ ] 手机号获取失败时降级到短信 OTP 且不阻塞流程
- [ ] 未配置微信凭据时 fail-closed，本地 mock 可跑通全流程

## ISSUE-05 小程序家庭视图与亲子共学（依赖 ISSUE-03、04）

**目标**：家庭视图完整落地小程序端，家长学生一起学习课程包内容并提交作品。

**范围**：

- 家庭视图页面族：今日课节、亲子共学内容（讲解 + AI 对话引导）、作品提交、星芽星球、成长报告
- 课程包内容只读渲染（版本不可变，ADR-0003），多孩切换
- 作品提交显式归属学生档案（与 ISSUE-03 同一契约）

**验收标准**：

- [ ] 完整路径可用：登录 → 绑定 → 选学生 → 看课节 → 共学 → 提交作品 → 星球/报告可见
- [ ] 课程内容在小程序端不可编辑；班级绑定版本正确渲染
- [ ] 家庭视图无五维数字与排名
- [ ] 弱网与提交失败重试可用，失败保留输入

## ISSUE-06 admin-web 三身份空间与合作方门户（依赖 ISSUE-02）

**目标**：admin-web 按 /teacher、/platform、/partner 三身份空间做路由级隔离，合作方门户落地。

**范围**：

- 路由重组为三个空间组；/partner 不依赖员工端组件（预留 ADR-0010 拆分边界）
- 合作方门户：已发布课程包与活动列表、内容详情，不含任何学生数据
- 平台管理员空间归集线索 CRM、课程版本治理、审核处置、审计
- 按身份裁剪导航与首页；平台管理员教师视角只读入口

**验收标准**：

- [ ] 三种身份登录后各自落位对应空间，互不可见其他空间路由（403/重定向）
- [ ] /partner 模块无员工端组件依赖（lint 边界或模块约束可验证）
- [ ] 合作方门户页面零学生数据字段
- [ ] 现有 admin-web 功能（提交队列、点评、CRM、平台页）在新结构下回归通过

## ISSUE-07 admin-web 响应式 H5 + PWA 与移动待办流（依赖 ISSUE-06）

**目标**：移动办公轻量化，手机版以待办流为核心，桌面版保留完整导航（ADR-0010）。

**范围**：

- PWA：manifest、图标、添加到主屏幕、Service Worker 缓存策略（仅静态资源）
- 移动待办流首页：待跟进线索、待审核社区内容、AI 草稿待处理、告警，按身份空间差异化聚合
- 关键高频页面移动布局：线索列表与流转、审核处置、草稿采纳/驳回
- 桌面导航不变；重编辑类（点评编辑、课程版本）不强制移动化

**验收标准**：

- [ ] 手机浏览器可完成：跟进一条线索至状态变更、处置一条待审核内容、采纳/驳回一条 AI 草稿
- [ ] 待办流按身份正确聚合且实时反映状态变化
- [ ] Lighthouse PWA 基础项通过；桌面布局无回归
- [ ] 二次验证在移动端可用

## ISSUE-08 微信侧上线配置（与 ISSUE-04 联调，收尾项）

**目标**：小程序具备提审与上线条件。

**范围**：小程序注册与类目提交（主体认证与非学科培训资质已齐备，走提交流程即可）、隐私协议与未成年人信息申报、`getPhoneNumber` 权限开通与费用充值、体验版灰度、域名与业务域名配置（HTTPS、CORS 白名单更新；生产域名待定，先用环境变量占位，随 OPS-05 收口）。

- [ ] 通过微信审核上架；生产 CORS/域名白名单生效
- [ ] `docs/pending-ops.md` 对应 OPS 项状态更新

## 明确不做（本批 Issue 边界）

- 对互联网公开的作品广场、搜索引擎收录、匿名互动（ADR-0008 边界）
- 员工微信小程序（ADR-0010）
- 在线支付、企微自动触达、多校区看板（维持 web-prd「明确不在首发」）
- 合作方门户独立域名/品牌定制（仅预留边界，触发条件见 ADR-0010）
