# 仓库模糊查询

## 触发词

搜仓库、找代码仓、火眼代码管理、我有权限的仓库

## 工具

`huoyan_search_repos`

| 参数      | 必填 | 说明                     |
| --------- | ---- | ------------------------ |
| `search`  | 否   | 关键字；不传则列可见仓库 |
| `page`    | 否   | 页码，默认 1             |
| `perPage` | 否   | 每页条数                 |

## 流程

1. 用户给出关键字（可选）
2. 调用工具，展示仓库名、路径、HTTP 地址
3. 用户选定 `projectRef` 后进入后续操作（查角色 / 列分支 / 建分支）

## 鉴权探活

Phase 1 可用 `huoyan_search_repos` + `perPage: 1` 验证 Gateway Key 与 userinfo 是否正常。
